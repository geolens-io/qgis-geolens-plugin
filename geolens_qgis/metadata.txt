changelog=
    0.2.1 - The panel no longer freezes QGIS while it waits for a GeoLens server
        - Connecting, searching, adding layers, renewing tile links and syncing run in the background, so a slow or unreachable server no longer freezes the QGIS window
        - The button that started a request is disabled until it finishes, and the status line says what is running
        - The layer is read-only while a sync sends its changes. If a sync stops partway, the changes that already reached the server are recorded, so the next sync sends only the rest
        - Add features works in a new project with nothing on the map. With "Only features in the current map extent" on, it used to fail with an HTTP 400 error
        - "No server yet?" opens the guide to running your own GeoLens server
    0.2.0 - Saved connections, a clearer panel and safer sync. The project now lives at github.com/geolens-io/qgis-geolens-plugin
        - Requires QGIS 3.44 or later
        - Keep several saved GeoLens connections, each with its own server and authentication, with a preset for the public GeoLens demo
        - GeoLens connections and datasets appear in the Browser panel and can be dragged onto the map
        - The dataset list shows layer icons, feature or band counts and quicklook previews, and can be filtered and sorted
        - Added layers carry the dataset's title, description, keywords, licence and link in their layer metadata
        - Sync sends only the fields you changed, so it no longer overwrites other people's edits, and it stops if the dataset was re-imported
        - API keys are stored in the QGIS authentication database. A key that 0.1.0 saved in plain text moves there when the panel opens, so QGIS may ask for your master password once
        - A saved key is sent only to the server it was saved for, and edits sync only to the server the layer came from
        - Vector tile URLs are fixed, and raster tile links renew before they expire
        - Requests go through QGIS networking, so servers behind bot filters no longer reject them
        - The panel opens on the first click, and Sync follows the layer selected in the Layers panel
        - New icons and an About dialog, with Spanish, French, German and Chinese translations
    0.1.0 - Initial experimental release
        - Browse and search GeoLens catalogs
        - Add vector tiles, raster tiles, and editable OGC API Features layers
        - Synchronize feature creates, updates, and deletes to GeoLens
